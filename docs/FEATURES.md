# Features

## Chat Interface
A responsive, dark-themed interface inspired by modern AI chat applications.

## Local Model Integration
Flask forwards messages to the locally running Ollama API.

## Markdown Rendering
Assistant responses can display headings, bold and italic text, lists, tables, links, and fenced code blocks.

## Code Syntax Highlighting
Highlight.js formats supported programming languages for easier reading.

## Conversation Context
Recent successful exchanges are sent with the next prompt to support follow-up questions. Context is temporary in the current frontend implementation.

## Theme Switching
Users can switch between dark and light appearance.

## Copy Responses
An action button copies an assistant response to the clipboard.

## Responsive Layout
The sidebar and chat interface adapt to smaller browser windows.

## Suggested Prompts
Example prompts help users explore explanations, coding, brainstorming, and planning.
