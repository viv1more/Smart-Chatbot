# Contributing

Contributions and suggestions are welcome.

## Guidelines

1. Keep changes focused and easy to review.
2. Test chat submission and error handling.
3. Check Markdown rendering for lists, tables, and code blocks.
4. Avoid committing credentials, environment files, virtual environments, or private data.
5. Update documentation when behavior changes.

## Reporting Issues

Include the operating system, Python version, Ollama version, model name, steps to reproduce the problem, and relevant error messages. Remove personal information and secrets before sharing logs.

## Pull Requests

Explain the problem being solved, summarize the changes, and provide testing steps.
